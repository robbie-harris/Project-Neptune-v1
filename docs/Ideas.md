# Ideas and future milestones

- Select an inspection niche: pipelines, hulls, submerged civil structures, or docking/maintenance stations.
- Add pipeline bends, supports, valves, and negative cylindrical distractors to challenge recognition.
- Introduce defects only after intact-pipe detection is reliable.
- Add stereo depth and relative geometry for approach/standoff.
- Fuse DVL, IMU, depth, and visual motion; implement degraded visibility behavior.
- Add controlled turbidity, instrument noise, bias, and time offsets in a later explicit milestone.
- Validate on real pool footage; document domain shift before field testing.
- Upgrade rendering hardware and benchmark actual end-to-end latency.
- Add autonomous inspection coverage, then controlled tool interaction with contact feedback.

These ideas do not expand the current implementation. Link new experiments to [[Research]], [[Decision Log]], and [[Implementation Plan]].
